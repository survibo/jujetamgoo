### S1. 연구 배경 — Grokking이란?
- **핵심 메시지**: "다 외운 줄 알았던 모델이, 한참 뒤에 갑자기 규칙을 깨친다."
- 구성 (불릿 2개):
  - 훈련 정확도는 빠르게 100%(암기), 검증 정확도는 한참 뒤 급상승(지연된 일반화) — 이 현상이 Grokking
  - 두 시점의 간격 = **Grokking gap** ("과적합 후 학습은 무의미하다"는 통념의 반례라는 점은 구두로만)
- 시각 자료: 훈련/검증 정확도 곡선 + Grokking gap 화살표 — **자체 제작**, 슬라이드의 주인공 (텍스트는 보조)
- 예상 시간: 1분 15초

### S2. 선행 연구와 그 한계
- **핵심 메시지**: "기존 연구는 전부 '두 수 계산 → 답 하나' 문제에 머물러 있다."
- 구성 (불릿 3개, 각 한 줄):
  - Power et al. (2022): modular arithmetic에서 grokking 최초 보고
  - Nanda (2023)·Liu (2022): 내부에서 Fourier 알고리즘·원형 임베딩 구조가 형성됨을 규명
  - **공통 한계**: 모두 `a ○ b mod p` 단일 토큰 분류 — 출력이 "구조를 가진 수열"인 경우는 미탐구
- 시각 자료: Liu et al. (2022) 3단계 임베딩 변화 그림(무질서 → 과적합 → 원형 구조) — **원본 인용 + 출처 표기**
- 예상 시간: 1분

### S3. 연구 목표와 독창성 — 왜 '정렬'인가
- **핵심 메시지**: "출력 전체가 수열인 seq2seq 과제로 Grokking 연구를 확장한다."
- 구성 (불릿 2개 + 예시):
  - 답 하나 예측과 달리, 수열 출력은 **출력 전체에 걸친 구조적 일관성**이 필요
  - 정렬 = 원소 간 비교 + 자리 배치가 결합된 가장 단순한 구조적 과제
  - 예시 한 줄: (3, 1, 4, 1, 5) → (1, 1, 3, 4, 5)
- 시각 자료: 기존 연구(a○b mod p → 답 1개) vs 본 연구(수열 → 수열) 대비 다이어그램 — **자체 제작**
- 예상 시간: 1분

### S4. 연구 문제
- **핵심 메시지**: 발현 여부 → 내부 구조 → 진행 양상, 3단계로 깊어지는 질문
- 구성 (RQ 3개, 부연 없이 질문 문장만):
  - **RQ1.** 정렬 과제에서 Grokking이 발현되는가? 정렬 규칙에 따라 어떻게 달라지는가?
  - **RQ2.** Grokking이 완료된 모델의 내부 표현은 어떤 구조를 가지는가?
  - **RQ3.** Grokking은 출력 전체에서 한 번에 일어나는가, 출력 그룹 단위로 나뉘어 일어나는가?
  - 하단 작은 글씨 한 줄: "미발현 역시 유의미한 결과로 해석" (심사 방어 포인트)
- 시각 자료: RQ 카드 3개 (텍스트 중심 슬라이드)
- 예상 시간: 45초

### S5. 실험 설계 ① — 세 가지 정렬 규칙
- **핵심 메시지**: "정렬 규칙을 두 개의 독립적인 축으로 분해했다."
- 구성 (축 소개 한 줄 + 다이어그램이 본체):
  - 정렬 키(항등/주기) × 위치 매핑(단조/비단조) 2축
  - 다이어그램 안에서 처리: 기준 A (1,1,3,4,5) / 기준 B mod 3 (3,1,1,4,5) + 잉여류 라벨 / 기준 C 교번 (1,5,1,4,3)
  - ※ 기준 B의 "동일 잉여류 내 오름차순" 규칙은 다이어그램 캡션으로 한 줄 명시 (포스터에서 누락됐던 부분)
- 시각 자료: 입력 → A/B/C 분기 다이어그램 (칸 색상으로 잉여류 표시) — **자체 제작**, 이 장의 본체
- 예상 시간: 1분 15초

### S6. 실험 설계 ② — 모델과 데이터
- **핵심 메시지**: "Grokking이 관찰될 수 있는 조건을 의도적으로 만든다."
- 구성 (불릿 3개):
  - 모델: 소규모 encoder-decoder Transformer (수열 입력 → 자기회귀적 수열 출력)
  - 데이터: V ≈ 10–12, N ≈ 5–6으로 **암기 가능한 규모** 제한 + multiset 단위 분할(검증셋은 처음 보는 값 조합만)
  - 학습: AdamW + 강한 weight decay, 장기 학습, 기준별 5개 시드
- 시각 자료: Encoder–Decoder 모식도 — **자체 제작**
- 예상 시간: 1분

### S7. 연구 방법 — 연구 문제별 분석 계획
- **핵심 메시지**: 세 RQ 각각에 대응하는 측정 방법이 준비되어 있다
- 구성 (RQ당 한 줄, 매핑 표가 본체):
  - RQ1 → 학습 곡선 분석: Grokking gap 측정, 정렬 기준 간 비교
  - RQ2 → 내부 표현 분석: embedding 차원 축소(PCA) → 수직선·군집·주기 구조 확인
  - RQ3 → 출력 연속성 분석: 출력 위치를 의미 단위로 묶은 그룹별 정확도 곡선
- 시각 자료: RQ → 방법 → 확인할 것 3행 매핑 표 — **자체 제작**, 이 장의 본체
- 예상 시간: 1분 15초

### S8. 예상 결과 및 기대효과
- **핵심 메시지**: "어느 쪽 결과가 나와도 해석 가능한 설계"
- 구성 (가설 한 줄씩 + 기대효과 한 줄):
  - 가설: ① 규칙이 복잡할수록(B·C) 발현 지연 ② 기준 B에서 주기·군집 구조 ③ 그룹 단위 부분적 grokking 가능성
  - 기대효과: grokking 연구를 단일 토큰 → 구조적 수열 출력으로 확장하는 첫 시도
  - 마무리 한 줄: 미발현조차 "어떤 구조가 grokking을 막는가"라는 답이 된다
- 시각 자료: 텍스트 중심 정리 (그래프 스케치 생략)
- 예상 시간: 1분
