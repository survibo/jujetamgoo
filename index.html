연구 방법 — 연구 문제별 분석 계획

연구 문제 분석 방법 무엇을 확인하는가
RQ 1 발현 학습 곡선 분석 훈련·검증 정확도 곡선, Grokking gap을 정렬 기준 간 비교
RQ 2 구조 내부 표현 분석 임베딩 차원 축소(PCA)를 이용하여 수직선·군집·주기 구조가 형성되는지 확인
RQ 3 양상 출력 연속성 분석 Token별 정확도와 전체 정확도를 비교하여 출력의 연속성 확인
모델 크기 · 학습률 · 데이터 비율을 세 기준 모두에서 동일하게 고정
기준마다 시드 5개 반복 — 발현 여부와 시점을 분포로 확인
설정한 최대 step까지 미발현이면 "관찰되지 않음"으로 기록하고 해석
곡선은 '언제', 표현은 '무엇을', 연속성은 '어떻게'
